Ключевые инженерные решения

🧠
Gateway

Умный API-шлюз и LLM Балансировщик

Единая точка входа (паттерн Singleton) для всех ИИ-моделей проекта. Автоматическое управление пулом прокси-серверов, Rate Limit контроль для бесплатных ключей, бесшовный переход между моделями через конфигуратор без изменения бизнес-логики.

Python WebSockets OAuth
🎧
ChromaDB RAG

Семантический Саунд-Дизайн (170+ ГБ)

Локальная векторная база данных. ИИ анализирует настроение сцены и самостоятельно подбирает музыку из 12 категорий. Модуль SFX извлекает звуки (шаги, двери, выстрелы) и накладывает их на мастер-трек с нормализацией громкости по вещательному стандарту EBU R128.

ChromaDB FFmpeg Pydantic v2
⏱️
Alignment

Миллисекундная синхронизация (WhisperX)

Речевые синтезаторы (TTS) не выдают точные таймкоды. В конвейер внедрена CUDA-ускоренная модель WhisperX. Она проводит принудительное выравнивание фонем (Forced Alignment) и привязывает каждый кадр видеоряда к словам диктора с точностью до 0.01 секунды.

PyTorch CUDA 11.8 NLTK
🎞️
VFI & SlowMo

Матрица видео-интерполяции (60 FPS)

Видео-генераторы (Kling/Veo) отдают сырой материал в 24 FPS. Для идеальной кинематографичной плавности реализован математический контур, перехватывающий короткие кадры и прогоняющий их через современные VFI-нейросети (EMA-VFI, MoMo) для масштабирования времени.

OpenCV TensorRT Diffusers

Инструменты режиссера (GUI-Студия)

Для ручного контроля качества на ключевых этапах разработаны нативные оконные приложения на Tkinter.

🎛️ Audio FX Tester

Визуальный интерфейс для наложения каскадных фильтров FFmpeg на голоса персонажей (рации, шлемы, роботы, эхо пещеры). Позволяет в реальном времени сгенерировать тест через API, прослушать его и в 1 клик записать пресет в JSON-паспорт героя.

🎨 Scene Visual Editor

Режиссерский пульт инспекции сгенерированных кадров. Встроенная связка с Microsoft Copilot позволяет на лету переписывать промпты (обход NSFW-ошибок серверов) и отправлять кадры на точечную фоновую перегенерацию без остановки основного конвейера.
